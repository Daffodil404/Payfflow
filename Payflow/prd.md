# 薪流 Payflow — macOS MVP PRD

---

# 一、产品概述

## 产品名称
薪流 Payflow

## 产品定位
一个 macOS 菜单栏实时薪资计数工具，将工作时间转化为可见收入。

## 核心价值
- 时间价值可视化
- 即时反馈
- 增强专注动力

# 四、功能需求

## 4.1 设置面板

### 字段

| 字段 | 类型 | 必填 | 默认值 |
|------|------|------|--------|
| 月薪 | Double | 是 | 无 |
| 本月工作日天数 | Int | 是 | 22 |
| 上班时间 | Time | 是 | 09:00 |
| 下班时间 | Time | 是 | 18:00 |
| 午休分钟 | Int | 否 | 60 |
| 更新频率 | 1/2/3 秒 | 否 | 1 |

### 校验规则
- 月薪 > 0
- 工作日天数 > 0
- 下班时间 > 上班时间
- 午休分钟 < 总工作分钟

---

## 4.2 薪资计算逻辑

### 输入
- monthlySalary
- workDaysInMonth
- paidWorkMinutesPerDay

### 计算公式

dailySalary = monthlySalary / workDaysInMonth

ratePerMinute = dailySalary / paidWorkMinutesPerDay

earnedToday = ratePerMinute * workedMinutes


### workedMinutes 规则
- 开始时间 → 当前时间
- 减去暂停时间
- 不跨日累计

---

## 4.3 计时功能

### 状态
- idle
- running
- paused

### 行为

| 操作 | 结果 |
|------|------|
| 开始 | 状态 → running |
| 暂停 | 状态 → paused |
| 继续 | 状态 → running |
| 结束 | 今日结算 → idle |

---

## 4.4 菜单栏展示

### 默认显示
¥123.45


### 下拉菜单

- 今日已赚
- 当前速率（¥/分钟）
- 已工作时长
- 开始/暂停/结束按钮
- 打开设置

### 更新频率
- 1–3 秒刷新一次
- 仅 running 状态刷新

---

## 4.5 下班提醒

### 逻辑
- 点击开始后计算今日结束时间
- 到点发送本地通知

### 通知内容
标题：
今日工作时间已到

正文：
是否结束薪流计时？

---

## 4.6 跨日逻辑

- 日期变化时自动结束昨日计时
- 今日归零
- 状态重置为 idle
